# Bink2 Converter

A fully client-side Bink 2 (`.bk2`) converter that decodes Bink2 in WebAssembly and produces transparent VP9/WebM for browser playback and download.

## Status

The decoder is based on FFmpeg 7.1.2 plus SharpEmu's Bink2 patch, with the alpha flag bug fixed so alpha-bearing `KB2n` files decode as `yuva420p` rather than overrunning the plane array.

The browser pipeline is:

`BK2 -> Bink2 decoder (WASM) -> YUVA420P -> libvpx VP9 alpha -> WebM -> <video>`

All conversion happens locally in the browser. Uploaded files are not sent to a server.

## Development

The static site lives in `web/`. The WebAssembly core is generated by GitHub Actions into `web/core/`; it is not hand-edited.

CI builds FFmpeg/libvpx with Emscripten, runs a browser smoke test, and deploys the resulting site to GitHub Pages.
